# Third-party notices

## svg-spinners — 3-dots-fade.svg

The inline three-dot indicator in `components/ui/huginn-thinking.tsx` is adapted
from `svg-css/3-dots-fade.svg` in [svg-spinners](https://github.com/n3r4zzurr0/svg-spinners)
by Utkarsh Verma. The source SVG is 482 bytes, uses `currentColor`, and has no
runtime dependency. The animation was kept to opacity only and the reduced-motion
state is handled by this product's UI.
